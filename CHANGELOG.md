# Changelog

## v1.0.0 - 2026-10-16

Initial release of Yerleşim Stüdyosu, an offline browser-based layout editor.

- Drag-and-drop layout editing with industrial and home object libraries.
- Plan and 3D views, object selection, movement, rotation, and collision checks.
- Measurement tools, undo and redo, and PNG export.
- Save and open layouts as JSON; work is also saved in the browser.
- Runs locally without a server or internet connection, using bundled three.js assets.
